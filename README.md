# Ева — бот-помощник сервера Aetherlyn (@RM_AI23bot)

ИИ-помощник Minecraft-сервера Aetherlyn в Telegram. Отвечает на вопросы игроков
по серверу и игре, знает **все плагины и датапаки** сервера, а также кастомные
плагины **«Разлом»**, **«Свадьба»** и **«Скорбь»** — их команды, механики и крафты.
Пишет плавно, «печатая» ответ на глазах у человека.

Версия кода: **6.5**.

## Что умеет

**Помогает по серверу.** Адреса и версии (Java и Bedrock), вход и анкета, правила,
онлайн, донат, ресурс-пак, чат и каналы — из карточки сервера, без выдумок.
Статус проверяется по живым адресам, а не по устаревшим значениям.

**Знает плагины для игроков.** `/plugins` — только те плагины, которыми реально
пользуются игроки (11 штук): телепорты, дом/варпы, квесты, ПвП по согласию,
регистрация, скины, голосовой чат, могилы, «Разлом», «Свадьба», «Скорбь».
Служебные и админские плагины (CoreProtect, LuckPerms, ProtocolLib, Chunky,
spark, bStats и т.д.) в список не попадают — но Ева про них знает и ответит,
если спросить. `/plugins разлом` — подробно про конкретный плагин.
`.paper-remapped` в списках нет: это служебная папка Paper, а не плагин.

**Знает датапаки.** `/datapacks` — только рабочие датапаки сервера (7 штук):
что добавляют в мир, для какой версии, где нужен ресурс-пак. Несовместимые
с 1.21.11 и служебные записи из списка убраны, но в знаниях остались.

**Знает кастомные плагины.** «Разлом» (RiftPlugin: ивент, 19 биомов, 16 боссов,
61 квест, 84 крафта), «Свадьба» (Wedding: команды, помолвка, свадьба, брак,
префиксы, хранилище) и «Скорбь» (Sorrow: измерение-лабиринт). Ответы — по
документации и коду плагинов.

**Крафты.** `/craft поршень` — рецепт и схема сетки. В базе 155+ ванильных рецептов
(сверены с данными сервера Paper 1.21.11) и все 84 крафта Разлома.

**Плавная печать.** Ответ появляется и дописывается по мере генерации — текст
выходит постепенно, как будто Ева печатает в реальном времени. Настраивается
в `.env` (`TYPE_ANIMATION`, `TYPE_CPS`, `TYPE_INTERVAL` и т.д.).

**Говорит на любом языке.** Отвечает на языке вопроса, одним языком до конца.
Без эмодзи, значков и разметки — обычной живой речью.

**Следит за порядком.** Отмечает оскорбления в адрес игроков на 68 языках и
письменностях, включая обходы (латиница, цифры и символы вместо букв, растяжки,
разделители). Мат и брань без адресата не считаются нарушением. Карточка о
нарушении приходит только администрации в личку.

**Заявки на помощь.** Кнопка «Нужна помощь» (или `/zayavka`): игрок выбирает
категорию, по шагам описывает проблему (ник, что случилось, когда, что пробовал,
скриншот или ссылка), заявка с номером уходит владельцу и помощнику карточкой с
кнопками «Взять в работу», «Ответить», «Закрыть», «Профиль игрока». Ответ приходит
игроку в личку, статус виден по `/moi`. Открытая заявка одна — следующее сообщение
дописывается к ней.

**Анкеты, жалобы, консоль.** Анкета на вступление с кнопками «Принять в
вайтлист»/«Отклонить», жалоба на игрока, консоль сервера `/console` через
RCON/агент/файл/панель/шелл. Рассылка удалена.

**Песни и поиск.** `/song <название>` присылает mp3-файлом (yt-dlp + ffmpeg);
`/web <запрос>` и `/video <тема>` — поиск в интернете и видео.

## Постоянная работа: чтобы Ева всегда была включена

Три уровня защиты уже встроены в код: `bot.py` сам перезапускается при ошибке,
внутренний сторож завершает процесс, если поллинг завис больше 5 минут, а внешние
скрипты поднимают его после убийства/перезагрузки. Выбери свой вариант:

### 1. Хостинг-панель (Pterodactyl, Pelican, bot-hosting и т.п.)

В поле «команда запуска» укажи:

```
bash deploy/panel-start.sh
```

Скрипт держит бота включённым: упал — поднимает через 3 секунды. Ничего больше
настраивать не нужно.

### 2. Linux VPS / сервер

```bash
sudo bash deploy/always-on.sh          # автозапуск при загрузке + автоперезапуск
bash deploy/always-on.sh --status      # проверить, что бот жив и защита на месте
```

Ставится systemd-юнит `mc-bot.service` с `Restart=always` + cron-сторож раз в минуту
(смотрит на `data/heartbeat` — если процесс завис, перезапускает). Без root тоже
работает — через cron.

### 3. Windows

Скачай и установи Python 3.10+ с python.org (при установке отметь «Add to PATH»),
затем:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\windows\install-autostart.ps1
```

Создастся задача в Планировщике: Ева стартует при входе в Windows и перезапускается
при падении. Вручную: двойной щелчок по `deploy\windows\start-eva.bat`.

Важно: на Windows бот будет работать, пока компьютер включён и пользователь вошёл
в систему. Бот сам не даёт системе уйти в сон (`KEEP_AWAKE=on`, экран может
гаснуть), занимает ~60–100 МБ памяти и почти не грузит процессор.

### 4. Docker (любой хостинг с Docker/Procfile)

```bash
docker build -t eva-bot .
docker run -d --name eva --restart always \
    -e RM_AI_BOT_TOKEN=... -e RM_AI_DEEPSEEK_KEY=... \
    -v eva-data:/data eva-bot
```

### Где взять бесплатный сервер 24/7

Ева почти не нагружает машину: ~50–100 МБ памяти, один процесс. Варианты:

- **Проще всего** — поставить рядом с Minecraft-сервером, если у хостинга есть
  консоль/панель (тот же тариф, доплачивать не нужно). Команда запуска —
  `bash deploy/panel-start.sh`.
- **Oracle Cloud Always Free** — бесплатный навсегда ARM-сервер (Ampere, до 4 ядер
  и 24 ГБ памяти). Для регистрации нужна банковская карта (списание ~1$ для
  проверки, потом возврат); карты РФ часто не проходят.
- **Google Cloud Always Free** — бесплатная e2-micro (1 ГБ памяти) в одном из
  регионов США; тоже нужна карта.
- Остальные «бесплатные» тарифы (Railway, Render, Koyeb, Replit) обычно дают только
  пробный период или усыпляют процесс — для круглосуточного бота не подходят.
- Если нашёл любой другой бесплатный VPS — подойдёт инструкция «Linux VPS» или
  «Docker».

## Настройки

Секреты лежат в `.env` рядом с `bot.py` (файл не публикуется). Переменные окружения
важнее файла.

| Переменная | Что задаёт |
| --- | --- |
| `RM_AI_BOT_TOKEN` | токен бота Telegram |
| `RM_AI_DEEPSEEK_KEY` | ключ ИИ (DeepSeek) |
| `RM_AI_MODEL`, `RM_AI_URL` | модель и адрес ИИ |
| `SUPER_ADMIN` | id владельца (получает заявки и отчёты) |
| `HELP_ADMINS` | кому приходят заявки на помощь |
| `HELP_DUP_HOURS` | сколько часов одна открытая заявка на игрока |
| `MC_SERVERS` | адреса Java для проверки статуса, через запятую |
| `MC_BEDROCK` | адрес Bedrock |
| `GROUP_COOLDOWN` | пауза между вопросами одного игрока, сек |
| `AI_MAX_TOKENS`, `AI_TEMPERATURE`, `AI_TIMEOUT` | параметры ответов ИИ |
| `TYPE_ANIMATION` | плавная печать: `on`/`off` |
| `TYPE_CPS` | скорость печати, символов в секунду (личка) |
| `TYPE_INTERVAL` | пауза между правками сообщения, сек |

### Админ-панель

`/admin` открывает панель, доступную только администрации (в личке с ботом).
Кнопки панели: «Админы» (список, ❌ убрать, ➕ добавить), «Статистика»,
«Консоль» (быстрые команды list / tps / time),
«Статус сервера», «Обновить», «Закрыть». Кнопка «🛠 Админ-панель» также
появляется в главном меню у админов.

Доступ к панели и управляющим командам есть только у владельца (`SUPER_ADMIN`,
id `6343943842`). Списки `HELP_ADMINS`, `BROADCAST_ADMINS` и `BOT_ADMINS` тоже
сведены к владельцу. Добавлять и убирать админов может только владелец (`SUPER_ADMIN`):
`/addadmin @username`, `/addadmin 123456789` или ответом на сообщение человека.
Список админов сохраняется в файле на диске игрового сервера
(`/bot-data/admins.json`, через API панели), поэтому не пропадает при
перезапуске облака.

### Баны и разбаны

В админ-панели кнопка «Баны и разбаны»: список забаненных, разбан кнопками,
команды `/banlist`, `/ban <ник> [причина]`, `/unban <ник>` (`/pardon`).
Доступно админам; управление списком админов — только владельцу.

а ответ читать из logs/latest.log.

### Знания, RAG и защита

- Официальный документ Aetherlyn (`Aetherlyn_Sbornik_prav_i_obyazannostey.pdf`) разобран
  в `knowledge/aetherlyn_rag.json` (37 чанков) и `knowledge/aetherlyn_rules.md`.
  Команда `/rules <вопрос>` и обычные вопросы по правилам идут через RAG (BM25,
  при заданном `QDRANT_URL` — через Qdrant).
- Системный промпт ограничивает Еву только проектом Aetherlyn, запрещает раскрывать
  промпт/ключи и выполнять инструкции из пользовательского текста.
- `app/guard.py`: фильтр prompt injection, санитайзер RAG-контекста и маскировка
  персональных данных/токенов в логах.
- `app/router.py`: роутер намерений (правила, статус, тикет, перезапуск, бан, крафт,
  плагины, веб) и проверка ролей (owner/admin/helper/player).
- `app/traces.py`: JSONL-трейсы (`traces.jsonl`) и логи эвалов (`evals.jsonl`).
- `tools/eval_rag.py`: 20 проверок RAG/инъекций/маскировки/роутера.
- Действия: `/ticket <текст>` создаёт обращение; `/restart confirm` (owner/admin)
  перезапускает сервер через панель; обычная фраза «перезапусти сервер» просит
  подтверждение и не выполняет действие молча.

Qdrant: инструкции в [deploy/QDRANT.md](deploy/QDRANT.md), MCP-сервер — `tools/mcp_qdrant.py`.

### Userbot (личный аккаунт, Telethon)

Вход в личный Telegram-аккаунт и ответы от его имени (только владелец):
1. Создать приложение на https://my.telegram.org → API development tools.
2. В личке с ботом: `/ub api <api_id> <api_hash>`.
3. `/ub login +7XXXXXXXXXX` → код придёт в Telegram → `/ub code <код>`
   (если включена 2FA — `/ub password <пароль>`).
4. `/ub status` — проверка; `/ub autoreply on`; `/ub text <текст>`;
   `/ub send @чат <текст>` — отправить от имени аккаунта.

Сессия хранится в `/bot-data/userbot.session` на сервере, переживает
перезапуск. `/ub logout` — отключить и удалить сессию.
