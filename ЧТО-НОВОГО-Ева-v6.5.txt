Ева 6.5 — Aetherlyn, плагины, датапаки и плавная печать
=======================================================

Главное
-------
1. Сервер переименован: бот больше не «Rice Mine», а помощник сервера Aetherlyn.
   Обновлены адреса, версии, порт Bedrock и вся карточка сервера:
   - Java: aetherlyn.mcmod.ru, для обхода aetherlyn34.mcmod.ru
   - Bedrock: 107.161.154.218, порт 25599
   - Версии: Java 1.21.1–1.21.11, Bedrock 26–26.60
   - анкеты — только через @RM_AI23bot, быть в чате проекта обязательно
   - добавлены ссылки: вся информация о сервере, спойлеры обновлений,
     ресурс-пак, новый Discord и ссылка для друга.

2. Ева знает все плагины и датапаки сервера.
   - /plugins — 31 плагин с коротким описанием, /plugins <название> — подробно:
     зачем нужен, команды игроку и админу, нюансы.
   - /datapacks — 11 датапаков: что добавляют в мир, для какой версии,
     где нужен ресурс-пак.
   - .paper-remapped объясняется как служебная папка Paper, а не плагин.
   - отмечены связки: GravesX и AxGraves + AxAPI, AdvancedTeleport и Essentials,
     ProtocolLib для Intave, PlaceholderAPI для TAB.

3. Ева знает кастомные плагины, которые делались для сервера:
   - «Разлом» (RiftPlugin): как попасть, портал и волны, 19 биомов, 54 структуры,
     96 видов живности, 16 боссов, 61 квест, 177 записей сюжета, команды и права,
     ограничения; все 84 крафта Разлома теперь ищутся через /craft.
   - «Свадьба» (Wedding 1.1.3): /marry и все подкоманды, GUI-меню, помолвка →
     свадьба → брак, планирование и RSVP, 240 префиксов, оплата ресурсами,
     общее хранилище, уровни отношений, развод.
   - «Скорбь» (Sorrow 2.4.0): измерение-лабиринт, вход через сон (шанс 10%),
     выход через настоящую дверь, механики 2.4, команды и права.
   Расхождения документации с кодом отмечены честно.

4. Плавная печать. Ответ появляется и дописывается на глазах: текст выходит
   постепенно, как будто Ева печатает в реальном времени. Работает и в личке,
   и в группе (в группе реже — чтобы не упереться в лимиты Telegram).
   Настройки в .env: TYPE_ANIMATION, TYPE_CPS, TYPE_INTERVAL,
   TYPE_GROUP_CPS, TYPE_GROUP_INTERVAL, TYPE_MAX_SEC, TYPE_MIN_CHARS.

5. «Всегда работает». Три уровня защиты:
   - bot.py сам перезапускается при ошибке (пауза 5→10→20→40→60 сек);
   - внутренний сторож: если поллинг завис больше 5 минут — процесс завершается,
     и его поднимает systemd/панель/сторож;
   - внешние скрипты: systemd Restart=always + cron-сторож, либо
     deploy/panel-start.sh для панелей хостинга, либо задача Windows.
   Новый режим python3 bot.py --loop — держит бота запущенным сам.

6. Убрано лишнее:
   - кнопка «Сайт проекта» и команда /site;
   - 111 команд-взаимодействий (/обнять, /tnt и т.д.) и /взаимодействия;
   - мёртвые обработчики кнопок и старая форма «песня»;
   - устаревшие данные «Rice Mine» из карточки сервера.

7. Исправлены рецепты крафтов. Раньше часть была с ошибками (наковальня,
   стойка для брони, лестница, бочка, коптильня, доменная печь, каменотёс,
   костёр, воронка, повторитель, компаратор, стрела, книжная полка и др.).
   Теперь рецепты сверены с данными Paper 1.21.11; добавлены кровать, ковёр,
   стол зачарований, маяк, зельеварка, котёл, якорь возрождения, кристалл Края,
   магнитный камень, железные двери и люки и т.д. Всего 155+ ванильных рецептов
   и 84 крафта Разлома.

8. Новые команды администрации: /kb (что в базе знаний), /kb reload
   (перечитать knowledge/*.md после правок). В меню команд Telegram добавлены
   /plugins и /datapacks, убраны /site и /interactions.

9. Обновлены README, .env.example, самопроверка (85 проверок), скрипты деплоя:
   deploy/panel-start.sh, Dockerfile, Procfile, deploy/windows/.
   В update.sh теперь копируется папка knowledge.
   Бот умеет писать лог в файл напрямую (LOG_FILE, UTF-8 без искажений) и
   на Windows не даёт компьютеру уйти в сон, пока работает (KEEP_AWAKE).

     а не плагин и не датапак);

     голосовой чат, могилы, Разлом, Свадьба, Скорбь;

   - /datapacks показывает только реально работающие датапаки (7): Incendium,
     Improved Pillager Outpost, Katters Structures, Nullscape, Tool Trims, Trek,
     True Ending. Несовместимые (Arboria, Clumps, Endcity) и служебные скрыты.
   Чтобы скрыть запись, в knowledge/*.md достаточно строки «видно: нет».

11. Анимация печати замедлена: 35 символов в секунду в личке (было 90),
    правка раз в 0.75 сек, максимум 18 секунд; в группах — 60 симв/сек.
    Настраивается в .env (TYPE_CPS, TYPE_INTERVAL, TYPE_MAX_SEC).

12. Появился облачный режим, чтобы Ева работала без компьютера:
    - бот слушает порт PORT и отвечает 200 на healthcheck (Render, Koyeb и др.),
      в ответе видно версию и число запросов;
    - самопинг: бот раз в 4 минуты запрашивает свой публичный адрес — для Render
      это входящий запрос, поэтому бесплатный сервис не засыпает;
    - готовы Dockerfile, render.yaml (blueprint на Render, план free) и
      .github/workflows/keepalive.yml — пинг раз в 5 минут как страховка;
    - проект выложен в репозиторий GitHub eva-bot, откуда Render
      разворачивает его одной кнопкой.

Проверка
--------
    python3 bot.py --selftest     → PASS
    python3 bot.py --menu         → 6 кнопок, без «Сайт проекта»
    python3 bot.py --kb           → записи: plugins, datapacks, rift, wedding, sorrow
    /plugins, /datapacks, /craft разлом, обычный вопрос — проверить в Телеграме.

Что осталось
------------
- Музыка (/song) требует yt-dlp и ffmpeg на хостинге; если их нет — бот честно
  скажет и пришлёт превью. В Docker-образе ffmpeg уже стоит.
- Полностью бесплатный круглосуточный хостинг — Oracle Cloud Always Free или
  запуск рядом с сервером Minecraft на том же тарифе (подробнее в README).

13. Ева переехала в облако: https://eva-bot-uulx.onrender.com
    (Render, free, регион Frankfurt) — работает 24/7 без компьютера.
    Исходники: https://github.com/Gnt8404/eva-bot (пуш = автообновление).
    GitHub Actions пингует сервис каждые 5 минут, чтобы Render не засыпал.
    Локальная копия на ПК отключена и остаётся резервом.

14. Подключена консоль сервера через RCON: /console <команда> из чата с ботом,
    добавление в вайтлист кнопкой анкеты и т.д. Настройки можно задать тремя
    способами: командами /rcon set|pass|test, в .env или переменными окружения
    RCON_HOST / RCON_PORT / RCON_PASS / RCON_ON (так сделано в облаке Render).
    Бот раз в 5 минут проверяет связь и пишет в лог, когда она появилась/пропала.

15. Если хостинг не отдаёт RCON-порт наружу, Ева управляет консолью через
    API панели Pterodactyl: в переменных окружения задаются PANEL_URL,
    PANEL_KEY и PANEL_SERVER. Команды выполняются через API, а ответ
    читается из logs/latest.log (вывод виден в Telegram). Каналы
    пробуются по очереди: RCON → агент → панель → шелл; недоступный RCON
    кешируется на час, чтобы не тормозить каждую команду.

16. Античит Eva установлен на сервер и работает:
    - версия 1.1.1 (Paper 1.21.11): проверки X-Ray, ESP, чит-клиентов/модов и автокликеров,
      адаптивная эвристика майнинга, предупреждения 1/3 -> 2/3 -> кик -> бан;
    - окно согласия при входе показывается только Java-клиентам 1.21.6+;
      Bedrock-игрокам (Geyser/Floodgate) и старым клиентам окно не мешает — исправлено в 1.1.1;
    - все флаги и данные проверок уходят администрации в Telegram через бота @RM_AI23bot
      (подтверждено: Telegram HTTP 200, доставка в 2 админ-чата);
    - команды только для владельца/админов: /eva check, /eva report, /eva toggle,
      /eva setban, /eva reload, /eva bot test, /eva online.

18. Плавная печать отключена по просьбе владельца (TYPE_ANIMATION=off):
    ответы приходят сразу одним сообщением, без постепенных правок.
    Включить обратно: в Render → Environment поставить TYPE_ANIMATION=on
    (или в .env при локальном запуске) и перезапустить бота.

    /deladmin, /remadmin, /удалитьадмина. Список админов сохраняется в файле на
    диске сервера (plugins/Eva/bot-admins.json), не теряется при перезапуске облака.
