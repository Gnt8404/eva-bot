# Формат файлов знаний (этот файл бот не читает, имя начинается с «_»)

Все файлы `knowledge/*.md` читаются модулем `app/kb.py` при старте бота.
Один файл — набор записей. Запись начинается со строки `## Заголовок`.

Простой пример:

```
## AdvancedTeleport
ключи: advancedteleport, телепорт, tpa, warp, дом, спавн
кратко: телепорты по серверу: /tpa, /warp, /home, /spawn
Этот плагин отвечает за телепорты.
Игроку доступны команды /tpa <ник>, /home, /spawn.
```

Правила:

1. Заголовок (`## `) — короткое имя сущности: плагин, датапак, раздел знаний.
2. Сразу после заголовка может идти строка `ключи: слово1, слово2, ...` —
   по этим словам бот понимает, когда подсунуть запись модели и в поиске.
   Пиши ключи в нижнем регистре, через запятую. Можно русские и английские.
3. Может идти строка `кратко: ...` — одна строка для списка команд `/plugins`
   и `/datapacks`. Без markdown, до 100 символов.
4. Дальше — свободный текст (markdown можно, но без таблиц и картинок):
   что это, зачем нужно на сервере, какие команды, что видит игрок.
   Внутри записи можно использовать `### Подзаголовки`.
5. Новая запись — только с новой строки `## ` (ровно два решётки и пробел).
6. Файлы, начинающиеся с `_`, бот не читает.
7. Текст пиши по-русски, факты — только проверенные. Если что-то не подтверждено,
   честно пиши «по документации», «в версии X поведение может отличаться».
