## Датапаки сервера Aetherlyn (обзор)
ключи: датапаки, датапак, datapack, datapacks, список датапаков, aetherlyn, что за датапаки, ресурс-паки, ресурспаки, сборка мира, версия сервера, какая версия сервера, какие версии поддерживаются, 1.21.11, paper, bedrock, 26.60, версия майнкрафта, ресурс пак, поставить ресурс пак, как установить ресурс пак, не видны текстуры, missing model, как установить датапак, как поставить датапак, датапак не работает, какие датапаки поддерживают 1.21.11
кратко: обзор 11 датапаков Aetherlyn: совместимость с 1.21.11, ресурс-паки, предупреждения
видно: нет
Сервер: Aetherlyn на Paper 1.21.11. Java-клиенты — 1.21.1–1.21.11 (ViaVersion/ViaBackwards), Bedrock — 26–26.60 (Geyser/Floodgate). Датапаки подключаются к конкретному миру: файлы кладутся в папку мира world/datapacks (у каждого измерения может быть своя папка) либо включаются командой /datapack enable; после установки нужен перезапуск сервера или /reload (для генерации — новый мир/новые чанки). Важно: датапаки, меняющие генерацию (биомы, структуры), влияют только на НОВЫЕ чанки — в уже исследованных местах изменений не будет.
Список датапаков Aetherlyn: Arboria, Clumps, Ichphilipps Endcity Better End, Improved Pillager Outpost, Incendium, Katters Structures, Lost Cities Modern Tweaks, Nullscape, Tool Trims, Trek, True Ending.
Совместимость с Paper 1.21.11: пробуем сверять по pack.mcmeta. Форматы данных (по Minecraft Wiki): 15 = 1.20–1.20.1; 48 = 1.21–1.21.1; 71 = 1.21.5; 80 = 1.21.6; 81 = 1.21.7–1.21.8; 88.0 = 1.21.9–1.21.10; 94.1 = 1.21.11; 101/107 = 26.1/26.2.
Подходят для 1.21.11 (94.1 в диапазоне): Improved Pillager Outpost (71–94.1), Incendium (94.1–101.1, но сборка «UNSUPPORTED»), Katters Structures (ровно 94.1), Nullscape (ровно 94.1), Tool Trims (64–107.1), Trek (48–107), True Ending (71–9999). Не подходят по формату, будут помечены как «incompatible»: Arboria (88.0 = 1.21.9–1.21.10), Clumps (88.0), Ichphilipps Endcity (15 = 1.20–1.20.1). Отдельно: Lost Cities Modern Tweaks (94.1) — это твик для мода The Lost Cities, на Paper без мода не работает.
Ресурс-паки: для Katters Structures клиентам нужен ресурс-пак (в папке «ресурс паки нужные для игры на Aetherlyn» лежит Katters Structures Resource Pack.zip), иначе кастомные предметы/иконки могут отображаться неправильно. Для Tool Trims пак нужно грузить и как датапак, и как ресурс-пак (в папке ресурс-паков лежит его копия) — по описанию самого пака «Has to be loaded as a data and resource pack». Для True Ending в папке ресурс-паков есть true-ending-dragon-music-v1.zip — новая музыка боя с драконом, ставится клиентам по желанию.
Нюансы: служебная папка .paper-remapped — не датапак и не плагин, это служебная папка Paper (подробности в разделе про плагины). Датапаки, переопределяющие ванильные структуры (End City, Pillager Outpost, True Ending и др.), не меняют уже сгенерированные структуры. Перед добавлением новых датапаков в существующий мир — бэкап: часть паков переопределяет теги/лут и может необратимо изменить поведение мира.
## Arboria
ключи: arboria, арбория, biome enhancement, биомы, генерация биомов, деревья, леса, озёра, улучшение биомов
кратко: улучшает ванильные биомы: деревья, растительность, редкие озёра; нужен 1.21.9–1.21.10
видно: нет
Что добавляет: датапак Arboria: Biome Enhancement v1.3.1 меняет генерацию ванильных биомов Верхнего мира (леса, тайга, джунгли, саванны, пустоши, горы, океаны и т.д.): переопределяет 51 биом в data/minecraft/worldgen/biome, добавляет 1212 configured_feature (в основном деревья — папки acacia, birch, dark_oak, jungle, spruce и др.), 957 placed_feature, 89 тегов и 29 новых структур-озёр (lake_forest, lake_birch, lake_lava, lake_sand, lake_gravel, lake_frozen, lake_taiga и т.п.) с 45 NBT-частями.
Зачем на сервере: делает природу Верхнего мира разнообразнее и красивее (больше вариаций деревьев, растительности, редкие озёра), не добавляя мобов или предметов.

Для Paper 1.21.11 (формат 94.1) пак по формату НЕ подходит: сервер пометит его как несовместимый. Нюансы: влияет только на новые чанки; в уже посещённых местах ничего не изменится. Ресурс-пак не нужен. Если игрок спрашивает «почему в лесу новые деревья/озёра только в далёких местах» — это как раз про новые чанки. Не путать Arboria с оформлением сервера.
## Clumps
ключи: clumps, клампс, опыт, xp, сферы опыта, орбы, слияние опыта, лаг от опыта, /function clumps:config
кратко: сливает сферы опыта и ускоряет подбор: /function clumps:config; нужен 1.21.9–1.21.10
видно: нет
Что добавляет: датапак Clumps v1.1.0 (автор lullaby6) — реализация «клампов» для опыта: соседние сферы опыта объединяются в одну (функция merge), есть опция мгновенного подбора опыта (instant_pickup), настройки через конфиг-функцию. Внутри 12 .mcfunction (merge, instant_pickup, config, tick, macro/give_xp и др.) и теги load/tick. Пак не модовый (Minecraft сам обрабатывает функции), не требует клиентских изменений.
Зачем на сервере: снижает лаги от большого количества сфер опыта в одном месте (фермы, данжи, ивенты) и ускоряет получение опыта.
Команды: настройка — /function clumps:config (выполняет админ/OP с правами на функции); открывается диалог настроек, где включаются merge/instant_pickup и радиусы. Других команд нет — это датапак, а не плагин.
Версия и совместимость: pack.mcmeta: pack_format 88, min_format 88, max_format 88 — данные для 1.21.9–1.21.10. Для Paper 1.21.11 пак по формату не подходит (нужен формат 94.1), сервер пометит его несовместимым.
Нюансы: по описанию проекта опция мгновенного подбора опыта несовместима с зачарованием Mending — если игроки жалуются, что «Mending не чинит вещи», проверьте настройку instant_pickup. Не путать с модом Clumps (Jared) — там другой принцип и другие настройки. Ресурс-пак не нужен.
